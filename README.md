# 정기고사 시감표

고등학교 정기고사 감독(시감) 배정 웹앱. `proctor.xlsm`(proctor_ver2026) 엑셀 매크로 프로그램의 기능을 옮기고 보강했습니다.

## 웹에서 바로 쓰기

https://kkhland.github.io/protor/ — 설치 없이 주소만 열면 됩니다. 입력한 내용은 서버로 전송되지 않고 각자의 브라우저에만 저장됩니다.

## 파일로 쓰기 (오프라인)

**`정기고사_시감표.html`** (= `dist/index.html`) 한 파일에 모든 코드가 들어 있습니다. 더블클릭해서 브라우저(크롬·엣지·웨일)로 열면 인터넷 없이도 동작합니다.
폴더 맨 위의 `index.html`은 개발용 원본이라 직접 열면 실행되지 않습니다.
작업 내용은 그 브라우저에 자동 저장되고, [저장]으로 JSON 파일을 받아 다른 컴퓨터로 옮길 수 있습니다.

## 엑셀 양식으로 한 번에 입력하기

화면에서 하나씩 입력하는 대신 엑셀 양식을 채워 올릴 수 있습니다.

1. [기본 정보] 화면에서 **[엑셀 양식 내려받기]** → `*_입력양식.xlsx`를 받습니다. (작성방법 시트에 설명이 들어 있습니다)
2. **시험기본정보** 시트에 고사 날짜·교시, 고사실, 교사, 보직을 채워 저장합니다.
3. **[작성한 엑셀 올리기]** 로 그 파일을 올립니다.
4. 양식을 다시 내려받으면 교시·보직 줄과 교사 명단이 채워진 **배정감독수정보**(필요 감독 수) · **감독배정**(x = 감독 불가, 1 = 고정, 못 들어가는 고사실) 시트가 들어 있습니다. 채워서 다시 올리면 됩니다.

양식을 다시 올려도 파일에 없는 내용은 이름·날짜를 기준으로 기존 작업에서 그대로 유지됩니다. 원본 `proctor.xlsm`도 같은 방식으로 올릴 수 있습니다.

## 시험 시간표 불러오기

[기본 정보] → **[시험 시간표 불러오기]** (또는 위쪽 [열기])에 학교 시험 시간표를 올립니다.

- **PDF**: 학교에서 배포하는 시험 시간표 PDF를 그대로 올리면 됩니다.
- **구글 시트**: `파일 → 다운로드 → Microsoft Excel(.xlsx)`로 받아 올립니다.

`교시` 칸과 `10월 1일(목)` 같은 날짜 머리글, `2학년/3학년` 학년 줄이 있는 표를 찾아 **시험 날짜와 날짜별 시작~종료 교시**를 설정합니다. 1학년 표처럼 머리글이 여러 번 나와도 합칩니다. 과목·시험 시각·출제 교사 글은 저장해 두었다가 시험 당일 시감표의 학년별 과목 줄과 `대표 교사` 줄에 씁니다. 이미 같은 날짜가 있으면 입력해 둔 필요 감독 수와 감독 불가 표시는 그대로 유지됩니다.

## 시험 당일 공유용 구글 시트

[감독표] 화면 위쪽 **시험 당일 공유용 시감표**에서 날짜를 고르고 **[구글 시트 만들기]**를 누르면 `○○고사 시감표_N일차` 구글 시트가 만들어지고 링크가 복사됩니다. 시트 구성은 학교 기존 양식과 같습니다.

| 시트 | 내용 |
| --- | --- |
| 시감표 | 교시별 학년 시험 과목, 학급(고사실)별 정감독·부감독, 대표 교사 |
| 교사별 | 교사마다 교시별 정감독·부감독 칸에 고사실 |
| 감독 누계 | 그날까지 누계, 그날 소계, 보직별 누계 |
| 시험 시간표 | 불러온 시험 시간표 (그날 열 강조) |

대기실 감독 등 세 번째 이후 보직은 정감독 칸에 적습니다.

### 처음 한 번: 구글 연결

앱은 브라우저에서만 돌기 때문에, 시트를 만들 구글 계정에 작은 **구글 앱스 스크립트**를 한 번 배포해 둡니다. [구글 연결 설정] 창에 순서와 코드(연결 토큰 포함)가 있습니다.

1. script.google.com에서 새 프로젝트 → 코드 붙여넣기 → 저장
2. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자)
3. 웹 앱 URL(…/exec)을 앱에 붙여넣고 [연결 테스트] → [저장]

저장 폴더(선택)와 “링크가 있는 모든 사용자 보기” 공유(선택)도 설정할 수 있습니다. 연결 전에는 **[같은 양식 엑셀로 받기]**로 받은 파일을 드라이브에 올려 “Google 스프레드시트로 열기”를 하면 같은 시트가 됩니다.

## 대기실 (고교학점제)

시험이 없는 학생이 생기는 교시의 대기실도 일반 고사실과 같은 방식으로 다룹니다.

1. [기본 정보] → 고사실 목록에 **대기실**을 추가합니다. ([학년·반 생성]의 “추가 고사실” 칸에 적어도 됩니다)
2. 보직 표에 **대기실 감독**(업무강도 30)이 기본으로 들어 있습니다. 정감독 100·부감독 50보다 가벼운 일로 계산됩니다.
3. [필요 감독 수]에서 교시별로 대기실에 필요한 인원을 적습니다. 대기 학생이 많은 교시는 2명, 없는 교시는 비워 두면 됩니다. 비운 교시는 감독표에서 그 줄이 숨습니다.

업무강도가 낮으므로, 대기실 감독을 여러 번 맡은 교사에게는 정감독이 더 배정되는 식으로 전체 부담이 고르게 맞춰집니다.

## 강사처럼 근무 조건이 제한된 교사

특정 날짜에 정해진 시수만 감독하는 교사는 [감독 배정] 화면에서 이렇게 처리합니다.

- **근무 조건** 칸(이름 오른쪽)을 눌러 **감독 가능 날짜**를 고릅니다. 고른 날 외에는 자동으로 감독 불가가 되어 x를 일일이 넣지 않아도 됩니다.
- **배정할 시간**에 시수를 적고 옆의 **🔒**를 눌러 고정합니다. [배정할 시간 자동 채우기]는 고정한 시수를 그대로 두고 남은 시간만 나머지 교사에게 나눕니다.
- 시수가 감독 가능한 시간보다 많거나, 고정한 시수의 합이 총 필요 시간을 넘으면 배정 전에 알려 줍니다.
- 엑셀 양식의 **감독배정** 시트에도 [시수 고정]·[감독 가능 날짜] 열이 있어 강사 명단을 한 번에 처리할 수 있습니다. (예: `10/13`, 여러 날은 `10/13, 10/14`)

## 작업 순서 (엑셀 시트 대응)

| 앱 단계 | 원본 시트 | 내용 |
| --- | --- | --- |
| 1 기본 정보 | 시험기본정보 | 고사 날짜·교시, 고사실, 감독 교사(이전 누적 업무강도), 보직·업무강도 |
| 2 필요 감독 수 | 배정감독수정보 | 교시·보직별 고사실 필요 인원 (빠른 채우기, 엑셀 붙여넣기, 교시 복사) |
| 3 감독 배정 | 감독배정 | X(불가)·고정 표시, 못 들어가는 고사실, 배정할 시간 자동 채우기, 자동 배정, 칸 교환·직접 편집 |
| 4 감독표 | 감독표 / 감독표(일별) | 전체·일별 표, 이름/감독번호 표시, 교사 강조, 인쇄(PDF) |
| 5 개인 시간표 | 감독표(개인) | 교사별 시간표, 전체 교사 1인 1쪽 / 4명 모아 인쇄 |
| 6 감독 현황 | — | 교사별 시간·날짜 분포·연속·보직 수·업무강도, 다음 고사로 누적 업무강도 이월 |

## 자동 배정 알고리즘 (`src/engine.ts`)

원본 VBA `감독배정풀코스`의 단계를 그대로 따르되 막히는 경우를 보강했습니다.

1. **사전 점검** — 배정할 시간 합 = 총 필요 시간, 교시별 가용 인원, 교사별 가용 시간
2. **감독 배정** — P값(남은 필요 ÷ 남은 빈칸)이 가장 큰 교시부터, 남은 배정 비율이 큰 교사에게. 막히면 교사 간 연쇄 교환(증가 경로)으로 해결하고, 구조적으로 불가능할 때만 “추가 배정할 교사”를 묻습니다. (원본의 X 표시를 옮기는 교환은 제약 위반이라 제외)
3. **날짜 분산** — 하루에 2시간 이상 몰린 감독을 다른 교사와 교환
4. **연속 감독 분산** — 같은 날 3연속 끊기(날짜 균형을 해치지 않는 교환만), 2연속을 비연속으로 재배치
5. **보직 배정** — 누적 업무강도가 낮은 교사부터 위쪽 보직. 고정 칸은 보직을 지정할 수 있음
6. **고사실 배정** — 무작위 섞기 + 못 들어가는 고사실 회피
7. **충돌 해소** — 같은 교시 안 2자/3자 순환 교환(보직 차이 작은 순)
8. **업무강도 분산** — 업무강도 높은 교사와 낮은 교사의 보직 맞교환(충돌이 생기는 교환 제외)
9. 여러 번 시도(기본 20회)해 충돌 → 3연속 → 날짜 편중 → 2연속 → 업무강도 표준편차 순으로 가장 좋은 결과 선택

## 개발

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/index.html 단일 파일 생성
npm run test:engine  # 배정 엔진 검증
npx tsx scripts/test-excel.ts  # ../proctor.xlsm 불러오기·내보내기 왕복 검증
```

GitHub Pages 등에 올릴 때는 `dist/index.html`만 올리면 됩니다.
